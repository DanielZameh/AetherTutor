# AetherTutor 🧠

**Multi-agent AI that adapts to every student**

AetherTutor is an experimental AI tutoring system that uses multiple collaborative agents to deliver personalized STEM learning. It combines adaptive teaching, interactive virtual labs, and knowledge tracking.

### Key Ideas
- Multiple specialized AI agents working together
- Personalized learning paths
- Interactive virtual labs
- Real-time knowledge graph style tracking of what the student understands

### Goal
Move beyond one-size-fits-all chatbots and create a tutoring experience that actually adapts to how each student learns.

### Tech Stack
- HTML / CSS / JavaScript

### Note on Development
This project was built with significant assistance from AI tools. I came up with the idea, designed the features, tested everything, and iterated on the outputs. The majority of the code was generated/assisted by AI.

### Status
Prototype / Hackathon project
